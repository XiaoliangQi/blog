# Xiaoliang Qi Blog

A fresh personal essay blog hosted from GitHub, with posts written in Markdown
and comments stored in GitHub Discussions through giscus.

## Quick Start

Install dependencies and run the local site:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Writing

Add posts as Markdown files in `content/posts`. See `POSTING.md` for the front
matter format.

## Comments

Comments are powered by [giscus](https://giscus.app/) and stored in
[GitHub Discussions](https://github.com/XiaoliangQi/blog/discussions).

The repository has Discussions enabled. For the embedded comment box to accept
new comments, the giscus GitHub App must also be installed for this repo.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: generate the static GitHub Pages site in `out/`
- `npm test`: build and verify the generated HTML
