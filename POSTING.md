# Posting

Add new articles as Markdown files in `content/posts`.

Each file needs front matter like this:

```md
---
title: "My New Essay"
date: "2026-08-14"
summary: "A one-sentence description for the home page."
---

Write the post here.
```

Use a lowercase filename with hyphens, such as `my-new-essay.md`. The filename
becomes the URL: `/posts/my-new-essay`.
